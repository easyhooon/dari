## Installation

Add the dependencies to your app module's `build.gradle.kts`:

```kotlin
dependencies {
    debugImplementation("io.github.easyhooon:dari:{{DARI_VERSION}}")
    releaseImplementation("io.github.easyhooon:dari-noop:{{DARI_VERSION}}")
}
```

The `dari-noop` module implements the same public APIs with no-op behavior, so your code compiles in release with no runtime overhead.

## Initialize

Dari starts automatically through AndroidX Startup. Call `Dari.init()` only when you need custom configuration:

```kotlin
class MyApp : Application() {
    override fun onCreate() {
        super.onCreate()
        Dari.init(
            context = this,
            config = DariConfig(
                showNotification = true,
                shakeToOpen = true,
            )
        )
    }
}
```

If you use the default configuration, you do not need any initialization code.

## Connect Your Bridge

Create an interceptor through `Dari.createInterceptor()` so the same app code compiles in debug and release builds:

```kotlin
val interceptor = Dari.createInterceptor(tag = "MyBridge")
```

Call it where requests enter your bridge and in the one function that sends responses back, not in each handler. In release builds, `dari-noop` returns `null`, so use safe calls:

```kotlin
inner class Bridge {
    @JavascriptInterface
    fun onBridgeRequest(handlerName: String, requestId: String, data: String?) {
        // Every request enters here
        interceptor?.onWebToAppRequest(handlerName, requestId, data)
        when (handlerName) {
            "getAppInfo" -> sendResponseToWeb(handlerName, requestId, true, appInfoJson())
            // ...other handlers reply through sendResponseToWeb too
        }
    }
}

// Every reply leaves through here
private fun sendResponseToWeb(handlerName: String, requestId: String, isSuccess: Boolean, data: String) {
    interceptor?.onWebToAppResponse(handlerName, requestId, data, isSuccess)
    val script = "onBridgeResponse(${JSONObject.quote(requestId)}, $isSuccess, ${JSONObject.quote(data)})"
    webView.post { webView.evaluateJavascript(script, null) }
}
```

Replies sent later, e.g. from a permission callback, are still paired by `requestId` as long as they go through the same function.
