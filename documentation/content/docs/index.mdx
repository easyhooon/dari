## What is Dari?

Dari is a debug inspector for WebView bridge communication, inspired by [Chucker](https://github.com/ChuckerTeam/chucker). On Android it captures and displays all WebView↔App bridge messages in a persistent notification and an in-app UI without changing your existing bridge logic. On iOS, the `Dari` Swift package sends them to the [desktop app](./desktop); see [iOS](./ios).

## Features

- **Real-time capture** of Web→App and App→Web bridge messages
- **Three-state tracking**: `IN_PROGRESS`, `SUCCESS`, `ERROR`
- **Dark mode** support
- **Shake-to-open** gesture to launch the inspector
- **Filters** by tag, status and text, plus direction on the desktop
- **Response time stats** per handler, with slow handlers highlighted
- **Export** captured messages as text or JSON
- **Optional Protocol Buffers inspection** with an app-provided decoder
- **No-op module** (`dari-noop`) for release builds with no runtime overhead
- **Fire-and-forget** support for one-way bridge calls
- **Same public API surface** across debug and release artifacts

## How It Works

Create a `DariInterceptor` with `Dari.createInterceptor()` and call it from your existing bridge callbacks. Each debug call is stored as a `MessageEntry` with request/response data, timestamps, and status. The inspector UI shows all entries in real time.

## Modules

| Module | Purpose |
|--------|---------|
| `dari-core` | Data models and interfaces |
| `dari` | Full implementation with UI, Room DB, notifications |
| `dari-noop` | No-op stub for release builds |
